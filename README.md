# 🏆 Competitive Programming Library

A personal collection of **algorithms, data structures, and programming techniques implemented in C++**, developed and maintained throughout my journey in competitive programming.

This library brings together implementations studied, practiced, and refined during my preparation for programming contests, particularly **ICPC-style competitions**.

## 📚 Contents

The library covers a wide range of competitive programming topics:

| Category | Description |
|---|---|
| **Algorithms** | General-purpose algorithms and problem-solving techniques. |
| **Data Structures** | Efficient data structures for different types of problems and queries. |
| **Graphs** | Graph traversal, shortest paths, connectivity, and other graph algorithms. |
| **Trees** | Tree algorithms, decomposition techniques, and tree-based structures. |
| **Mathematics** | Number theory, combinatorics, modular arithmetic, and mathematical algorithms. |
| **Geometry** | Computational geometry algorithms and geometric operations. |
| **Strings** | String matching, processing, and related algorithms. |
| **Tools** | Auxiliary utilities for competitive programming. |

## 🎯 Purpose

The main purpose of this repository is to maintain a personal reference of algorithms and data structures, consolidating knowledge acquired through years of studying and practicing competitive programming.

It also serves as a collection of reusable implementations for solving algorithmic problems and preparing for programming contests.

## ⚙️ Usage

All implementations are designed to work with the **C++ template provided in this repository**. These implementations follow a personal coding style developed over years of practice, often relying on conventions and implicit assumptions that may not be immediately clear to others. As such, this library is primarily intended as a personal reference rather than a general-purpose resource.
